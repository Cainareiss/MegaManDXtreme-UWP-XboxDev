Mega Man original sprite reference

Use playerx-original-sheet.png as the exact sheet base used by the game.
The frames folder contains each original frame cropped from that sheet.
playerx-original-frames.json and .csv contain x, y, width, height, origin,
image point, and collision data extracted from the Construct project.

For the safest replacement, keep the same 512x512 sheet size and place each
new sprite inside the same frame rectangles listed in the CSV/JSON.
